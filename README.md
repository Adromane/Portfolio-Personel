## 🚀 Lancer le projet en local

### Prérequis

- Node.js et npm installés
- Git installé

### Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/Adromane/Portfolio-Personel.git
   ```

2. Accéder au dossier :

   ```bash
   cd Portfolio-Personel
   ```

3. Installer les dépendances :

   ```bash
   npm install
   ```

4. Lancer le projet :

   ```bash
   npm start
   ```

L'application sera généralement accessible à l'adresse `http://localhost:3000`.
